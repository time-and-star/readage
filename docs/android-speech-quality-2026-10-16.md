# Android 整句粗糙听感排查（2026-10-16）

用户反馈：多个手机均有整句粗糙、砂纸感，S21 听感不通过。本轮只排查，不修改正式模型、产品源码、学习档案或安装状态，不编译、同步、打包。

## 实测结论及边界

同一 Sherpa ONNX 1.13.8 主机环境、CPU 两线程、1×、相同音色表 / tokens / eSpeak 数据，对正式 Android int8 权重与已有诊断 fp32 权重分别生成美音 af_heart / sid 3、英音 bf_emma / sid 21，每种两句，共 8 个真实音频。语言参数与正式插件一致（模型 en-us，生成 extra.lang 为 en-us / en）。音频直接保存，无滤波、均衡、去噪或音量归一化。

| 检查 | 结果 |
| --- | --- |
| 本地 int8 模型、voices、tokens 对照既有 bundle 清单 | SHA-256 一致；不是本地文件意外损坏的证据 |
| 美音 / 英音在 Android 声音表与电脑 Kokoro.js 文件中的嵌入 | 每个 float32 完全相同，最大差值 0 |
| 采样率 / PCM 写出源码 | 使用引擎 sampleRate，float PCM 原值入队、按实际写入数量推进；未发现额外增益或错误整数转换 |
| 8 个样本的振幅 | 峰值 0.353–0.634，无 NaN / Inf、无超出 ±1 样本；本批未复现削波或整句恒定满幅 |
| int8，4.8 kHz / 9.6 kHz 窄带峰相对附近频谱底部 | 四个样本分别 13.1–14.8 dB / 16.1–18.7 dB |
| fp32，同指标 | 2.1–3.5 dB / −1.6–4.7 dB，明显减弱 |
| 既有 PCM 队列 / 分段 / 缓存主机回归 | 10 / 10 通过；不能证明真机听感 |
| ADB 设备 | 列表为空；未执行手机合成、播放、安装或设备验收 |

窄带指标用 scipy Welch PSD：24 kHz、2400 点窗口、1200 点重叠；目标频点 ±10 Hz 最大 PSD 与距目标 50–200 Hz 的 PSD 中位数作比值。这个指标衡量局部突出的频率成分，不等于整体噪声级或音质评分。

**目前最有证据的原因方向是 int8 合成输出中的窄带伪影**：该差异在进入 Android AudioTrack 前已存在，且两种英语音色均复现。不能将其写为已证明全部砂纸感由此造成，更不能宣称已修好。本次是 Windows x64 CPU 的同权重对照，Sherpa wheel 核心 DLL 为 ORT 1.28.2；APK 的 ARM / ORT / 音频设备链路独立，不能用主机速度或结果代替真机。

上游有同模型 int8 的相似高频杂音及 ARM 异常输出报告：[sherpa-onnx #3754](https://github.com/k2-fsa/sherpa-onnx/issues/3754)。报告涉及较旧 Sherpa 1.13.4，维护者因提交模板标为 invalid，未确认根因；本轮结论依赖本地实测而非把该报告当作已确认缺陷。
