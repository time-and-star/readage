### 最终源码与检测结果

采用固定翻译指令的 KV 前缀复用，范围止于所选正文之前的第一个空行。截断指令的分词结果须与完整输入的开头逐 token 一致；只有整段指令 token 与缓存完全相同时才复用，语言、目标或指令变化就清空 KV。调用官方 `llama_memory_seq_rm` 删除其后的旧正文与输出；不支持部分删除时回退清空全部 KV。命中与未命中都按同一指令 / 正文边界分批，使输入批次不随上次所选正文改变；正文每次完整计算并更新 logits，采样器仍重新创建并接受完整本次提示词。只有成功 EOS 请求归还上下文和指令 token；借出后取消 / 超时 / 失败同时销毁上下文并丢弃对应缓存元数据。缓存只在进程内，不增加学习数据或持久化记录。
