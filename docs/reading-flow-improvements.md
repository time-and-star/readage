# 阅读流程改进

本轮范围：修复基础查词对 AI 的依赖；明确失败状态；自动恢复文章和段落；轻量词卡与主动句子解释；普通学习数据串行写入、跨标签刷新和失败重试；插件安装连接引导；插件查询纳入实际日期的学习统计；可选难度反馈；明确熟练度是行为估计。

实施与验收顺序：
1. 词典优先、缓存与真实错误。AI 停止时已收录单词仍可查询，失败不生成查询学习证据。
2. 数据写入锁、跨标签刷新、错误重试及外部学习统计。并发更新不覆盖，重复同步不重复统计，跨时区保持发生日期。
3. 自动续读、轻量词卡和句子工具条。重新打开恢复段落，选中不会自动复制或打开讨论，Esc 和外部点击关闭。
4. 插件连接向导和主应用安装说明。首次用户能看见当前状态和下一步，正常使用自动同步。
5. 可选难度反馈与记忆估计说明。反馈影响后续推荐，测评仍非必填，不声称已经验证学习效果。
6. 全量测试、类型检查、应用和扩展构建、实际浏览器流程验证。

保留本轮前已有未提交修改。真实学习效果需要后续用户研究，不以自动化测试代替。
