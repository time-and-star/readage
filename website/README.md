## 菜单与留言

致谢根据根 README 整理，包含用户点名的 OpenAI / Codex、腾讯混元团队、@hehonghui/awesome-english-ebooks，以及模型和推理项目。关闭、点外部或 Esc 返回；留言草稿在当前页面关闭后保留，刷新页面不会保留未发布草稿。

留言免登录。服务器签发一年有效的随机访客 Cookie（HttpOnly / SameSite=Lax，HTTPS 配置时追加 Secure），同一浏览器能看到自己的“你”标记并恢复上次发布的称呼；清除 Cookie 后成为新访客，昵称不代表经过验证的身份。Cookie 仅在打开留言板时创建，不用于统计。

发布需要输入四位图形验证码，答案不发给前端。验证码与 Cookie、随机令牌和请求 IP 绑定，三分钟过期、一次使用；错误会换码并保留正文。请求来源、正文长度、重复验证码和发布频率在服务器检查，不能靠改前端跳过。每位访客每十分钟最多 3 条、每日 20 条；每个 IP 每十分钟最多 5 次成功发布、15 次发布尝试和 30 次验证码申请。图形验证码加限流是基础防滥用，不宣称能阻止所有自动化。

所有访客读取同一服务器留言，按新到旧每页 20 条。留言按纯文本渲染，不执行输入的 HTML。数据和签名密钥位于忽略目录 `website/.data/`，不在静态资源白名单内，与学习库无关；服务器重启保留留言和身份，未使用的验证码会失效。停止服务后备份整个 `.data/`，不要公开或提交其中的数据库和密钥。

GitHub 图标来自 [GitHub Primer / Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-24.svg)，原 MIT 许可保存在 `assets/octicons-LICENSE.txt`。Georgia 使用系统现有字体，未分发字体文件。

使用 Node.js 22.13 或更新版本。在项目根目录运行 `node website/preview.mjs`，访问 **http://127.0.0.1:4175**。默认只绑定回环地址，不开放项目根目录；静态文件使用白名单，留言接口独立于学习服务。
