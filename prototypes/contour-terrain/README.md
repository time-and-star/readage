# 地形工坊 · 独立 2.5D 原型

提供一块 `24 × 24 m` 的等距地形：山谷 / 岛丘 / 台地底稿、等高线、米制网格、水面，以及抬高、降低、平滑、整平和撤销操作。本轮范围是地形编辑原型。

## 直接打开

双击本目录的 [`terrain.html`](terrain.html)，用浏览器打开即可。页面的样式与代码已装入单文件，离线可用，无需启动阅读应用或安装服务。

地形会保存到该浏览器的本地存储，重新打开同一入口可继续编辑；撤销历史保留在当前页面会话。不同浏览器、文件入口和开发地址各自保存独立地形。浏览器拒绝本地保存时，页面会提示，当前会话仍可编辑。

## 操作

- 选择底稿，再使用“查看”点选地块，读取标高与坡度。
- 选择“抬高 / 降低 / 平滑 / 整平”，在地块上按住或拖动。笔刷半径以米为单位；抬高 / 降低力度显示米，平滑 / 整平力度显示百分比；整平可输入目标标高。
- 用“撤销上一步”恢复上次操作；“恢复初始地形”返回当前底稿，两种底稿切换和恢复操作也可撤销。
- 开关等高线、米制网格和水面；等高距可选 `0.5 / 1 / 2 m`。
- 桌面滚轮缩放，空格加拖动或“拖动视图”按钮平移；查看模式也可直接拖动平移。点击比例按钮返回 100%，点击“完整查看地块”自动适配画面。
- 画布获得焦点后，箭头平移、`+ / −` 缩放；`Ctrl/Cmd + Z` 撤销，`Esc` 返回查看。输入框内键盘用于编辑数值。
- 触屏单指点选或雕刻，双指缩放；选择“拖动视图”后单指平移。窄屏工具与参数在地形画面下方，选好工具后向上滚动回到画布。

## 尺度

`100%` 即 `zoom = 1`：一格为 `1 m × 1 m`，平地投影 `52 × 26 px`；每升高 `1 m` 垂直上移 `26 px`。缩放同时作用于水平投影与高程。坡面按四角实际高度投影，格子会变形，尺寸不能固定套用平地菱形。

## 修改与开发预览

本目录的 `dist/` 保存可直接编辑的静态源码：`index.html`、`style.css`、`app.js`、`geometry.js` 和 `software-renderer.js`。运行时无需编译。

在项目根目录启动开发预览：

```powershell
node prototypes/contour-terrain/serve.mjs
```

打开 [本地预览](http://127.0.0.1:4318)。修改 `dist/` 后刷新预览；再运行以下命令，将最新样式与代码装入交付单文件：

```powershell
node prototypes/contour-terrain/build.mjs
```

此命令使用项目已有的 `esbuild`，生成本目录 `terrain.html`，不会运行阅读产品的 `npm run build`。

操作验收范围、截图与三端状态见 [ACCEPTANCE.md](ACCEPTANCE.md)。独立浏览器原型已完成相关桌面与触摸模拟检查；Windows Electron / Android 应用尚待后续接入和设备验收。
