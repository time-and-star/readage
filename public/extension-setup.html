在其他网站阅读，也能随手查词

首次安装需要在浏览器扩展管理中操作一次。安装后，选中英文单词，再点「查词」即可自动记录。

1. 下载并解压

下载 ReadAge 插件

把 ZIP 解压到一个固定文件夹。后续保留该文件夹，浏览器需要从这里加载插件。

使用项目文件时，也可直接选择项目下的 extension/dist 文件夹。

2. 在 Chrome 或 Edge 中加载

  1. Chrome：在地址栏输入 chrome://extensions；Edge：输入 edge://extensions。
  2. 打开「开发者模式」，点击「加载已解压的扩展程序」。
  3. 选择包含 manifest.json 的文件夹。
  4. 点击浏览器工具栏的拼图图标，找到 ReadAge 并固定。

3. 连接并开始查词

点击 ReadAge 图标，按「连接学习应用」完成授权。然后打开一个英文网页，再点击「为当前网站启用查词」。只有你授权的网站会启用。

当前主应用地址：。插件默认连接 localhost:3000；若你使用其他地址，在插件的「连接设置」中修改。

去英文网页选中一个单词，点击出现的「查词」，确认释义和保存状态。记录会自动同步。

遇到问题

  • 本地服务未启动：双击项目中的 start-local.cmd，或运行 npm run start:local。保持服务进程运行。
  • 没有查词按钮：先授权当前网站；浏览器设置页、PDF、输入框不支持。
  • 显示待同步：在使用插件的同一浏览器配置中打开主应用。网页关闭时，插件会暂存记录。
  • 更新插件后：在扩展管理页点「重新加载」，再刷新英文网页。
无需账号。Chrome 和 Edge 各自保存数据；清除浏览器数据前，请在「我的学习」导出备份。
