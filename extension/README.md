# ReadAge 浏览器查词插件

在普通网页选中一个英文单词，点击「查词」，查看音标和中英文释义。查询成功后自动保存一次学习记录；打开同一浏览器中的 ReadAge 主应用即可同步。

## 0.3.2 界面与体验

- 面板保留杂志式排版，精简为网站操作、单行同步状态和「打开 ReadAge」；应用地址等低频操作收进「设置」。
- 右上角开关立即暂停或恢复全部网站；当前网站的按钮可单独暂停该网站，不影响其他网站，也不会清除学习记录。
- 查词卡片默认仅展示词头、音标与还原信息、第一条双语释义和保存状态。其余义项、例句和词形统一收进「更多」，需要时可完整查看。在窄窗口和网页边缘会自动调整位置。
- 连接失败可在原卡片重试，同一次选词不会重复记账。Esc 或关闭按钮可关闭，键盘选择单词后可直接操作查词按钮。
- 待同步数量只统计当前学习应用地址的记录。主应用关闭时明确显示「已暂存」，收到应用确认后才显示已同步；打开应用会优先复用已有标签页。
- 仅保存学习记录的原有规则保持不变：词典未找到、查询失败和输入框选词不会生成记录。

## 安装（Chrome / Edge 桌面版）

1. 在项目根目录运行 `npm run build:extension`。安装目录是 `extension/dist`，本次实现已生成。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择本项目的 **extension/dist** 文件夹。
4. 将 ReadAge 固定到浏览器工具栏。首次点击「连接 ReadAge」完成授权和检查。本地默认 `http://localhost:3000`；其他地址在「设置」中填写 HTTPS 根地址，再点「保存并授权」。
5. 保持主应用服务运行（本地运行 `npm run dev`）；连接异常时，面板会提示。展开「设置」可重新检查连接。
6. 访问想阅读的网站，点击网站名称旁的「启用」，允许该网站权限。选中英文单词后点击浮动的「查词」按钮；已启用时，同一位置的「暂停」可停用该网站。
7. 点击「打开 ReadAge」。已暂存的记录自动合并到主应用。主应用打开时，新记录也会自动同步。

更新插件后，在扩展管理页面点「重新加载」，并刷新已打开的网页。主应用也需要部署本次更新；仅安装扩展不能让旧版主应用自动支持同步。

## 数据与同步

- 主应用是熟练度的唯一计算方。一次查词沿用站内「曝光＋查询」证据，不等于掌握，也不会直接按查词次数加分。
- 查词记录先保存到扩展，再发送给主应用；主应用确认写入后才从待同步队列移除。网络异常、主应用关闭、浏览器重启不会清空待同步记录。
- 保存实际查询时间和当时的时区，迟到记录补回原来的学习日。每条记录有唯一标识，重复发送不会重复计分。
- 一个浏览器配置内共享数据。Chrome、Edge、其他电脑、不同浏览器配置各自独立，不做云同步。
- 更换主应用地址时，旧地址的待同步记录不会混入新地址；切回旧地址可以继续同步。`localhost`、`127.0.0.1` 和不同端口是不同地址。
- 仅处理主动查询的单词，不扫描网页全文。来源标识是去掉查询参数和片段后的网页地址的 SHA-256，不保存原地址或正文。
- 插件缓存最近写入的最多 500 个词条。主应用服务停止时，缓存词仍可查并产生记录；未缓存的新词提示服务不可用。
- 插件中的「启用网页查词」开关立即生效。网站权限可以在浏览器的扩展管理中撤销。
- 卸载插件或清除扩展数据会删除未同步记录。主应用的导出备份包含已同步学习记录及重放日志，不包含插件尚未同步的队列。

## 支持范围

首版支持普通网页正文中的单个英文词（包括撇号和连字符）。不支持短语/整句翻译、输入框、编辑器、内嵌框架、内置 PDF 阅读器、浏览器内部页面和扩展商店页面。无痕模式不属于首版支持范围。

## 故障排查

| 情况 | 处理方法 |
| --- | --- |
| 选词后没有按钮 | 检查插件已启用、当前网站已授权；更新插件后刷新网页；确认选中的是正文中的一个词。 |
| 词典服务不可用 | 启动主应用服务，核对地址，再运行「检查连接」。查词卡片可点击「重试查询」，无需重新选词。 |
| 一直显示待同步 | 打开已配置地址的新版主应用，等待初始化；然后点击「立即同步」，查看提示。失败的记录保留以供重试。 |
| 记录未出现在另一浏览器 | 本版不做跨浏览器同步；请在查词所用浏览器的同一配置中打开主应用。 |
| 存储空间不足 | 先使用主应用的导出备份功能；不要直接清理插件数据，以免丢失待同步记录。 |

## 实现与验证

- Manifest V3；只有按网站授权后才注册内容脚本。扩展后台访问词典服务，网页不直接持有词典请求权限。
- 同步桥只在配置的主应用源启用；校验浏览器发送方、顶层页面、消息版本、字段和批次大小。学习写入使用同源 Web Locks，提交后跨标签页通知刷新。
- 首次同步某个词时保存其不可变历史基线，后续该词的查词和站内阅读事件进入持久化重放日志。基线、事件先保存，再重建派生状态；失败可重试恢复。
- 旧版曾清理的原始事件无法凭空恢复：保留现有每日证据、实际复习日志及 RME 计数，并保留可用的历史曝光记录。对有完整事件记录的时间段，按时间顺序重新分类和结算。独立保存的口语产出分数不受影响。
- 不增加数据库版本；重放日志使用现有 metadata 存储，并支持 localStorage 降级、后续 IndexedDB 迁移及原有备份导入导出。

```text
npm run check:extension
npm run build:extension
npm run lint
```

真实浏览器验证脚本：`node --import tsx scripts/smoke-extension.mjs`。需要可用的 Playwright；可用 `PLAYWRIGHT_MODULE` 指定其模块路径，用 `BROWSER_EXECUTABLE` 指定 Chrome/Edge 程序路径。脚本使用独立临时配置和本地测试页面，不读取日常浏览器数据；仅测试副本预先授权两个本地测试源，交付的 manifest 保持按网站申请权限。

## 新版连接引导

本机先运行 `npm run start:local`，或双击 `start-local.cmd`。访问主应用的 `/extension-setup.html` 可下载并查看逐步安装说明。插件弹出页点击「连接学习应用」会完成授权、连接检查和打开应用；随后在英文网页启用当前网站。地址修改收纳在「连接设置」。

主应用现在会把插件查词纳入原查询日期的连续学习天数和近期活动，已有同步日志也会自动计入。记忆库迁移完成后，会将原 localStorage 字节副本存入 IndexedDB metadata 并核验，再释放重复占用；正常备份包含这些副本。
